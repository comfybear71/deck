### Stop button (report item 15)

Read twice. `shouldStop` is checked at the top of every loop iteration, i.e. after the current render and its chain, before the next render starts. That is correct for "stop the next clip". It is now also checked before a scene-block still is generated (a paid call). I could not reproduce "next clip still started" in code; if it happens again, note whether the clip that started was the one already rendering when Stop was tapped (expected, already paid) or a genuinely later one.
